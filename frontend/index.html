ℹ️ How the scan works
Orion indexes your entire drive in 3 phases:

① Scanning — Walks every folder on your drive collecting file paths. No files are added to the database yet. This is the longest phase (~20-40 min on 1TB via os.walk).

② Inserting — Extracts metadata (name, size, type, date) for each file and writes it to the SQLite database in batches of 5,000. You will see the database fill up rapidly here (~5-10 min).

③ Complete — All files are searchable. Stale entries (deleted files) are cleaned up. The database persists on disk forever.

Future startups: Orion skips the scan if the database is less than 4 hours old — startup is instant. Background re-index runs every 4 hours silently.

With Everything installed: The scanning phase drops from ~40 min to ~5 seconds, since Everything reads the raw NTFS Master File Table directly.
